How this works

This page plays the part of the financed phone. Its lock agent holds the device key that a technician loaded at handover, and it checks unlock codes on its own, with no network. That's how a phone in an area with no data can still be unlocked from an SMS code.

Each code is signed for this one phone, says how long the phone stays unlocked, and works once.
